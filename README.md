# ස්වර මඟ (Swara Maga) - පෙරදිග සංගීතය ඉගෙනුම් වේදිකාව
### Sri Lankan School Oriental Music Digital Learning Platform (public scope: Grades 6–11)

**“ස්වර මඟ”** යනු ශ්‍රී ලංකාවේ 6 සිට 11 ශ්‍රේණිය දක්වා පෙරදිග සංගීතය හදාරන පාසල් සිසුන් සහ ගුරුවරුන් වෙනුවෙන් සකස් කරන ලද, ජංගම-පළමු (Mobile-first) අන්තර්ක්‍රියාකාරී ඩිජිටල් ඉගෙනුම් වේදිකාවකි. අන්තර්ගතය මූලාශ්‍ර සමාලෝචනයට යටත් වන අතර, සම්පූර්ණයෙන් සත්‍යාපිත හෝ නිෂ්පාදන-සූදානම් බවක් මෙම ව්‍යාපෘතිය ප්‍රකාශ නොකරයි.

---

## 🌟 ප්‍රධාන අංග ලක්ෂණ (Key Features)

### 1. ශිෂ්‍ය ඉගෙනුම් අත්දැකීම (Student Experience)
- **ඉලක්ක පාදක ඉගෙනුම් මාර්ග (Learning Paths)**: විභාග හෝ තනි සංකල්ප ඉලක්ක කරගත් පූර්වාවශ්‍යතා පිරික්සන ඉගෙනුම් මාර්ග 6+.
- **අන්තර්ක්‍රියාකාරී පාඩම් 18+ (Interactive Lessons)**: නාදය, සප්ත ස්වර, ලය හා තාල, ථාට හා රාග, දේශීය වාද්‍ය භාණ්ඩ, ගැමි ගී, නූර්ති/නාඩගම් නාට්‍ය සංගීතය, ගී රසවින්දනය සහ සංගීත තාක්ෂණය ආවරණය වන සම්පූර්ණ පාඩම් මාලාවක්.
- **සජීවී බ්‍රවුසර් ශ්‍රව්‍ය මෙවලම් (Zero-Copyright Web Audio API)**:
  - **ස්වර යතුරුපුවරුව (Swara Keyboard)**: මන්ද්‍ර, මධ්‍ය, තාර සප්තකවල ස්වර වාදනය හා ආරෝහණ/අවරෝහණ වාදන මෙවලම.
  - **තාන්පුර ශ්‍රැති ජනකය (Tanpura Drone)**: Sa-Pa සහ Sa-Ma ශ්‍රැති සහිත අඛණ්ඩ අනුනාදක ශ්‍රැති මෙවලම.
  - **තාල දෘශ්‍යකාරකය (Tala Visualizer)**: ත්‍රීතාල, දාද්‍රා, කෙහර්වා, රූපක් තාල සඳහා තාල සජීවීකරණය හා තබ්ලා බෝල් ශබ්ද.
  - **ලය හා තාල තට්ටු කිරීමේ අභ්‍යාසය (Rhythm Tapping Game)**: තාලයට අත්පුඩි ගැසීමේ හෝ තට්ටු කිරීමේ නිරවද්‍යතාව මනින ක්‍රීඩාව.
  - **දේශීය ස්වර තාරතා හඳුනාගැනීම (Microphone Pitch Detector)**: 100% බ්‍රවුසරය තුළ හඬ විශ්ලේෂණය (කිසිදු ශබ්දයක් සේවාදායකයට උඩුගත නොවේ).
  - **ස්වර ප්‍රස්තාර සකසනය (Notation Arranger)**: ස්වර නිවැරදි පිළිවෙළට සකසන අභ්‍යාස.
- **බහුවිධ ප්‍රශ්නාවලි සහ විභාග පුහුණුව (Multi-format Quizzes & Exams)**: බහුවරණ, ගැලපීම්, පෙළගැස්වීම්, ශ්‍රව්‍ය හඳුනාගැනීම් ප්‍රශ්න 60+ ක් සහ සා.පෙළ (6-11 ශ්‍රේණි) මාදිලි ප්‍රශ්න පත්‍ර.
- **සිංහල සංගීත ශබ්දකෝෂය (Glossary)**: සවිස්තරාත්මක විවරණ සහිත සංගීත පාරිභාෂික වදන් 40+.

### 2. ගුරු මෙවලම් පද්ධතිය (Teacher Hub)
- ශ්‍රේණි මට්ටම් සහ NIE නිපුණතා (Competencies) අනුව පාඩම් පෙරහන.
- තමන්ගේම පාඩම් එකතුවක් (Lesson Collection) සකස් කිරීම.
- සිසුන් සමඟ බෙදාගත හැකි සරල පැවරුම් කේත (Assignment Codes) සහ සබැඳි නිර්මාණය.
- මුද්‍රණය කළ හැකි පාඩම් සටහන් (Printable Lesson Outlines).

### 3. අන්තර්ගත සමාලෝචන හා පරිපාලන පද්ධතිය (Admin & Review Workflow)
- අදියර 8 කින් යුත් දැඩි සමාලෝචන ක්‍රියාවලිය (Draft -> Source Checked -> Sinhala Reviewed -> Music Reviewed -> Rights Checked -> Published).
- එක් එක් අන්තර්ගතය සඳහා නිල NIE මූලාශ්‍රය, පිටු අංකය, සහ බලපත්‍ර තොරතුරු සනාථ කිරීමේ පාලන පුවරුව.

### 4. ළමා ආරක්ෂාව හා දත්ත රහස්‍යතාව (Child Safety & Privacy)
- කිසිදු වෙළඳ දැන්වීමක් නොමැත (No Ads).
- ලියාපදිංචියකින් තොරව සම්පූර්ණ අන්තර්ගතය විවෘතයි.
- මයික්‍රෆෝන භාවිතය තනිකරම බ්‍රවුසරය තුළ සිදු වන අතර කිසිදු හඬ පටයක් උඩුගත නොවේ.
- අඩු දත්ත මාදිලිය (Low-Bandwidth Mode) සහ නොබැඳි (Offline PWA) භාවිත සහාය.

## 🚀 ධාවනය කිරීමේ උපදෙස් (Quick Start)

### අවශ්‍යතා
- Node.js 18+ (හෝ Node 20+)
- NPM 9+

```bash
# 1. පරායත්තතා ස්ථාපනය
npm install

# 2. දේශීය සංවර්ධන සේවාදායකය
npm run dev

# 3. පරීක්ෂණ ධාවනය
npm run test

# 4. නිෂ්පාදන ගොඩනැගීම
npm run build
```
